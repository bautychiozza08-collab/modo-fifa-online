# 🏆 Juego de Campeones

Este es un proyecto web desarrollado en Python donde se simula un juego de campeones.

## 🚀 Tecnologías

* Python (Flask)
* HTML
* CSS

## 📁 Estructura

* `app.py` → archivo principal
* `datos.json` → datos del juego
* `plantillas/` → HTML
* `estático/` → estilos

## ▶️ Ejecutar en local

1. Crear entorno virtual:
   python -m venv .venv

2. Activar entorno:
   .venv\Scripts\activate

3. Instalar dependencias:
   pip install -r requisitos.txt

4. Ejecutar:
   python app.py

## 🌐 Deploy

El proyecto está preparado para desplegarse en Render.
